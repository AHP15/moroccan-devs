## قبل أن نبدأ

تحتاج إلى مفتاح API. سجّل حساباً مجانياً على [serpapi.com](https://serpapi.com/users/sign_up)،
وستجد المفتاح في لوحة التحكم. الخطة المجانية تكفي تماماً لهذه السلسلة.

**لا تضع المفتاح في الكود مباشرةً.** ضعه في متغيّر بيئة، لأنّ المفتاح الذي يصل إلى مستودع Git
عام يُعتبر مكشوفاً حتى لو حذفته في commit لاحق — سجلّ Git يحتفظ به.

```bash
export SERPAPI_KEY="ضع_مفتاحك_هنا"
```

## أول طلب

<CodeTabs tabs={['Python', 'JavaScript', 'cURL']}>
<Fragment slot="python">

```python
import os
import serpapi

client = serpapi.Client(api_key=os.environ["SERPAPI_KEY"])

results = client.search({
    "engine": "google",
    "q": "أفضل مقاهي الدار البيضاء",
    "google_domain": "google.co.ma",
    "gl": "ma",   # البلد
    "hl": "ar",   # لغة الواجهة
})

for result in results["organic_results"][:5]:
    print(f'{result["position"]:>2}. {result["title"]}')
    print(f'    {result["link"]}\n')
```

<Fragment slot="javascript">

```javascript
const params = new URLSearchParams({
  engine: 'google',
  q: 'أفضل مقاهي الدار البيضاء',
  google_domain: 'google.co.ma',
  gl: 'ma',
  hl: 'ar',
  api_key: process.env.SERPAPI_KEY,
});

const response = await fetch(`https://serpapi.com/search?${params}`);
if (!response.ok) throw new Error(`SerpApi returned ${response.status}`);

const data = await response.json();
for (const result of data.organic_results.slice(0, 5)) {
  console.log(`${result.position}. ${result.title}`);
  console.log(`   ${result.link}\n`);
}
```

لاحظ استخدام `--data-urlencode` في مثال cURL. هذا ليس تفصيلاً تجميلياً: الاستعلام العربي يحتوي
على أحرف غير ASCII ومسافات، ووضعه مباشرةً في الـ URL دون ترميز يعطي طلباً مشوّهاً أو خطأ.

## قراءة بنية الاستجابة

الاستجابة كائن JSON واحد بمفاتيح عليا، أهمّها:

| المفتاح | ما يحتويه |
| --- | --- |
| `search_metadata` | حالة الطلب، معرّفه، والوقت المستغرق |
| `search_parameters` | المعاملات كما فُهمت فعلياً من طرف الخدمة |
| `search_information` | العدد الإجمالي للنتائج ومعلومات الاستعلام |
| `organic_results` | النتائج الطبيعية، وهي ما يهمّنا غالباً |
| `related_questions` | صندوق «أسئلة ذات صلة» |
| `knowledge_graph` | بطاقة المعلومات الجانبية، إن وُجدت |
| `pagination` | روابط الصفحات التالية |

وكل عنصر داخل `organic_results` له هذا الشكل:

```json
{
  "position": 1,
  "title": "عنوان الصفحة",
  "link": "https://example.com/page",
  "displayed_link": "https://example.com › page",
  "snippet": "المقتطف النصّي الظاهر تحت العنوان"
}
```

**نصيحة تشخيصية:** حين لا تحصل على النتائج المتوقّعة، اقرأ `search_parameters` أولاً. هي تخبرك
كيف فُهم طلبك فعلياً، وغالباً ما تكتشف أنّ معاملاً كتبته خطأ جرى تجاهله بصمت.

## المعاملات التي تهمّ فعلاً

ثلاثة معاملات تحدّد أي نسخة من صفحة النتائج تحصل عليها، والخلط بينها مصدر شائع للأخطاء:

- `google_domain` — أي نطاق Google تستعلم منه، مثل `google.co.ma` أو `google.com.eg`.
- `gl` — رمز البلد المكوّن من حرفين، يحدّد التحيّز الجغرافي للنتائج.
- `hl` — رمز اللغة، يحدّد لغة الواجهة وله أثر على النتائج نفسها.

بالإضافة إليها: `location` لتحديد مدينة بعينها، و `device` للتبديل بين `desktop` و `mobile`
(وهما يعطيان ترتيبين مختلفين فعلاً)، و `start` للتصفّح عبر الصفحات.

انتبه هنا إلى تفصيل مهمّ: كان بالإمكان سابقاً طلب مئة نتيجة دفعة واحدة عبر المعامل `num`،
لكنّ Google أوقفت دعم ذلك سنة 2025، وصارت معظم الطلبات تعيد عشر نتائج بغضّ النظر عن قيمته.
النتيجة العملية أنّ أي أداة ما تزال تعتمد على `num=100` تظنّ أنّها ترى مئة نتيجة وهي ترى عشراً،
وتُبلغ خطأً بأنّ نطاقك غير موجود. الطريقة الصحيحة اليوم هي التصفّح بـ `start` صفحةً صفحة.

سنستعمل هذه المعاملات بجدّية في المقال القادم، لأنّها بالضبط ما يجعل قياس الترتيب في السوق
العربي مختلفاً عمّا يفترضه معظم الناس.

## التعامل مع الأخطاء

الخطأ الأكثر شيوعاً في الإنتاج هو `429 Too Many Requests`، ويعني أنّك تجاوزت المعدّل المسموح.
الاستجابة الصحيحة له ليست إعادة المحاولة فوراً، بل الانتظار بتباعد أُسّي:

```python
import time
import requests

def search_with_retry(params, max_attempts=5):
    for attempt in range(max_attempts):
        response = requests.get("https://serpapi.com/search", params=params, timeout=30)

        if response.status_code == 429:
            # تباعد أُسّي: 1، 2، 4، 8 ثوانٍ
            wait = 2 ** attempt
            time.sleep(wait)
            continue

        response.raise_for_status()
        return response.json()

    raise RuntimeError("تعذّر إتمام الطلب بعد عدّة محاولات")
```

إعادة المحاولة فوراً بعد `429` تزيد الضغط ولا تحلّ شيئاً. التباعد الأُسّي يعطي الخدمة فرصة
للتنفّس ويرفع احتمال نجاح المحاولة التالية.
